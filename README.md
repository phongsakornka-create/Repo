# My Card — นามบัตรดิจิทัลแบบ Datasheet

หน้าเว็บส่วนตัวหน้าเดียว เขียนด้วย HTML + CSS + JavaScript ล้วน
ไม่ต้องติดตั้งอะไรเพิ่ม ไม่มี build step

หน้าตาออกแบบให้เหมือน **datasheet ของชิ้นส่วนอิเล็กทรอนิกส์** โดยลิงก์ติดต่อทั้งหมด
ถูกวาดเป็นผังขาของไอซี (pin configuration)

---

## เปิดดูยังไง

ดับเบิลคลิกไฟล์ `index.html` ได้เลย

ไฟล์นี้ใช้สคริปต์ธรรมดา ไม่ใช่ ES Module จึงทำงานบน `file://` ได้
(ถ้าอยากได้ auto-reload ตอนแก้ ใช้ Live Server ก็ได้เหมือนกัน)

> ปุ่มคัดลอกอีเมลจะทำงานเฉพาะตอนเปิดผ่าน `http://localhost` หรือ `https://`
> ถ้าเปิดแบบ `file://` ระบบจะเปิดโปรแกรมอีเมลแทน ซึ่งเป็นพฤติกรรมที่ตั้งใจไว้

---

## โครงสร้างไฟล์

```
my-card/
├── index.html          โครงสร้างเนื้อหา — จุดที่ต้องแก้ทั้งหมดอยู่ที่นี่
├── css/
│   ├── theme.css       สี ฟอนต์ ระยะห่าง — แก้ที่เดียวเปลี่ยนทั้งหน้า
│   └── style.css       การจัดวาง — ยังไม่ต้องแก้ก็ได้
├── js/
│   └── main.js         สคริปต์เล็ก ๆ 3 อย่าง
├── assets/
│   └── favicon.svg     ไอคอนบนแท็บเบราว์เซอร์
└── README.md
```

การแยก 3 ส่วนนี้คือหลัก **Separation of Concerns**
HTML บอกว่า *มีอะไร* / CSS บอกว่า *หน้าตาเป็นยังไง* / JS บอกว่า *ทำอะไรได้*

## สิ่งที่ต้องแก้ให้เป็นของตัวเอง

ในไฟล์ `index.html` มองหาคอมเมนต์ `✏️ แก้ที่ N` จะเจอ 11 จุด

- [ ] 1 · ชื่อบนแท็บเบราว์เซอร์
- [ ] 2 · คำอธิบายตอนแชร์ลิงก์
- [ ] 3 · รหัสนักศึกษา
- [ ] 4 · ชื่อ-นามสกุล
- [ ] 5 · บทบาท / สิ่งที่กำลังทำ
- [ ] 6 · ตารางสเปก (เพิ่มลบแถวได้)
- [ ] 7 · ลิงก์ติดต่อทั้ง 8 ขา
- [ ] 8 · ชื่อบนตัวชิป
- [ ] 9 · ย่อหน้าแนะนำตัว
- [ ] 10 · ป้ายทักษะ
- [ ] 11 · ชื่อในกรอบท้ายกระดาษ

ในไฟล์ `css/theme.css` ลองเปลี่ยน

- [ ] `--accent` เป็นสีที่ชอบ
- [ ] `--grid-size` เพื่อเปลี่ยนความถี่เส้นตาราง
- [ ] `--radius` เป็น `0` เพื่อให้มุมคมแบบแบบเขียน หรือ `14px` ให้ดูนุ่ม

**ข้อควรระวัง:** พิมพ์โค้ดขณะเปิดแป้นภาษาไทย จะได้สระหรือวรรณยุกต์ติดหน้าคำ
เช่น `ิbody` หรือ `ี--accent` ซึ่งทำให้ CSS บรรทัดนั้นเงียบหายไปโดยไม่มี error
ถ้าแก้แล้วไม่เปลี่ยน ให้สงสัยข้อนี้ก่อนเสมอ

## ทำให้ลิงก์เปิดได้จากทุกที่

1. push โปรเจกต์ขึ้น repo ของตัวเองบน GitHub
2. ไปที่ **Settings → Pages**
3. เลือก **Source: Deploy from a branch** → branch `main` → folder `/ (root)`
4. รอประมาณหนึ่งนาที แล้วเปิด `https://<ชื่อ-github>.github.io/<ชื่อ-repo>/`
